# DeepSeek Family (`V2-Lite`, `V2`, `V3`, `R1`, `V3.2-DSA`) — Zero-GPU `nnScaler` Adaptation

Hardware-decoupled `nnScaler` model adaptation and declarative parallelization package for the
**DeepSeek** model family (`DeepSeek-V2-Lite` 16B, `DeepSeek-V2` 236B, `DeepSeek-V3` / `DeepSeek-R1`
671B-A37B, and `DeepSeek-V3.2-Exp` 671B with DeepSeek Sparse Attention), built directly following
[`.github/skills/nnscaler-model-adaptation/SKILL.md`](../../.github/skills/nnscaler-model-adaptation/SKILL.md).

All tracing, custom operator shape/partition inference, PAS policy compilation, collective adapter
generation, and `gencode*.py` verification run on a **CPU-only machine (`0` GPUs)** via weightless
`meta` tracing (`param_init_strategy=ParamInitStrategy.SHARD`).

---

## Architectural Blockers Solved

| Subsystem | Upstream HuggingFace Blocker | `examples/Deepseek` Solution |
|---|---|---|
| **MLA `expand_kv`** (`V2`, `V3`, `V3.2`) | Mutates sliced views (`key_states[..., :dn].copy_(k_nope)` / `.copy_(k_rot)`) breaking FX SSA, and `k_rot.expand(-1, H, -1, -1)` freezes the head axis (`128^`). | 3D `kv_b_proj` + custom `deepseek_mla_concat_kv` (`b h s dn^, b 1^ s dr^ -> b h s dk^`): shards `k_nope` across `h` (`TP`), keeps shared MQA `k_rot` (`[B, 1, S, 64]`) replicated in forward, and All-Reduces `d_k_rot` across TP in backward. |
| **V2 Complex RoPE** (`DeepseekV2`) | `torch.polar` + `view_as_complex` / `view_as_real` emit opaque ops and `complex64` tensors. | Rewritten in-memory to bit-identical real interleaved `(cos, sin)` `IRDimops` (`loss_diff = 0.0`). |
| **V3.2 Sparse Attention (`DSA`)** | `@torch.no_grad()` `DeepseekV32Indexer` uses 4D broadcasted `bmm` (`[B,S,H,D] @ [B,1,D,T]`) + dynamic `topk` / `scatter`. | Wrapped in `deepseek_v32_dsa_index_mask` (`b s^ h^, ... -> b 1 s^ t^`) with CPU/meta `fake_fn` and frozen indexer weights matching `@torch.no_grad()`. |
| **Sparse MoE Routers & 3D Experts** (`V2`, `V3/R1`, `V3.2`) | `@use_experts_implementation` calls `scatter_`, `sort`, `histc`, `cumsum(dtype=...)`, and dynamic `.nonzero()` loops. | Static-shape `deepseek_v2_moe_route` (`greedy` & `group_limited_greedy`) + `deepseek_v3_moe_route` (`sigmoid` + `e_score_correction_bias` group TopK), paired with **Mode A** (`expand_moe_ops: false` default `deepseek_moe_grouped_gemm` with `TransformRule` for EP) and **Mode B** (`expand_moe_ops: true` opt-in `permute -> chunk -> grouped_linear -> unpermute` for `EP` & `ETP`). |
| **Vocabulary Output Head** (`102,400` / `129,280` vocab) | `F.cross_entropy(..., reduction='mean')` locks `N^ C^`, forcing multi-GiB FP32 logits `AllGather`. | `DeepseekCausalLMTaskWrapper` uses `reduction='sum' / valid_token_count`, unlocking `vocab_parallel` on `lm_head` and token-sharded CE. |

## Quickstart (0 GPUs Required)

### 1. Compile Flagship DeepSeek-V3 / R1 (`671B-A37B`, 32 GPUs `PP=4 × EP/TP=8`)
```bash
PYTHONPATH=. python examples/Deepseek/compile.py \
    --model deepseek-v3 \
    --strategy examples/Deepseek/strategies/v3_ep8_pp4.json \
    --out-dir /tmp/deepseek_v3_bundle \
    --batch-size 2 --seq-len 128
```

### 2. Compile DeepSeek-V2-Lite (`15.7B-A2.4B`, 4 GPUs `EP=4 / TP=4`)
```bash
PYTHONPATH=. python examples/Deepseek/compile.py \
    --model deepseek-v2-lite \
    --strategy examples/Deepseek/strategies/v2_lite_ep4_tp4.json \
    --out-dir /tmp/deepseek_v2_lite_bundle
```

### 3. Compile DeepSeek-V3.2 with Sparse Attention (`DSA`)
```bash
PYTHONPATH=. python examples/Deepseek/compile.py \
    --model deepseek-v3.2 \
    --strategy examples/Deepseek/strategies/v32_dsa_ep8_pp4.json \
    --out-dir /tmp/deepseek_v32_bundle
```

### 4. Opt-in Expanded MoE Primitives (`--expand-moe-ops true`)
```bash
PYTHONPATH=. python examples/Deepseek/compile.py \
    --model micro-v3 \
    --strategy examples/Deepseek/strategies/v3_expanded_etp4.json \
    --expand-moe-ops true \
    --out-dir /tmp/deepseek_v3_etp4_bundle
```

### 5. Run Full Verification Suite (Golden CPU Parity + Zero-GPU Compilation)
```bash
PYTHONPATH=. python examples/Deepseek/tests/run_all_tests.py
```

## Verification Bundle Artifacts (`--out-dir`)

Every `compile.py` invocation exports:
- `00_model_and_strategy.json` — Model metadata, strategy config, PAS rule hit counts, pre/post-PAS summaries, and per-rank collective counts.
- `02_ir_pre_pas.txt` & `02_ir_audit.json` — Full pre-PAS `IRDimops` annotations, shapes, and static audit (`num_opaque_fw_ops == 0`, `num_dynamic_tensors == 0`).
- `03_ir_post_pas.txt` & `03_adapters.json` — Post-PAS sharded sub-tensors, pipeline segments, and synthesized `IRAdapter` communication primitives.
- `04_generated/gencode*.py` — AST-validated per-rank executable Python modules generated by `nnScaler`.
